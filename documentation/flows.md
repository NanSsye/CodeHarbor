# Flows

本文档描述需要跨越权限、设备、本地执行或外部副作用的流程。已实现的步骤标注为“已落地”，其余仍需 guarded live 验收。

## 设备绑定

**参与者**：已登录用户、浏览器、云端、Gateway.exe。

**前置条件**：Gateway 已安装并能启动 Codex 检测；用户已登录网站。

1. Gateway 首次以注册凭证建立设备连接，Relay 生成 6 位、10 分钟有效的一次性配对码。（已落地）
2. 用户在网页选择“配对码”并提交；云端以哈希校验、单次消费并绑定当前管理员账户。（已落地）
3. 云端返回账户令牌和 `deviceId`，网页自动选中该设备；Gateway 保存独立设备凭证并保持 WSS。（已落地）
4. 网页显示在线状态；配对码过期、重放、撤销和跨账户绑定必须拒绝。（自动化已覆盖，真实手机待验收）

拒绝条件：配对码过期、已使用、账户无权绑定、设备已撤销或签名不匹配。

## 远程 Codex 任务

1. 浏览器提交 `task.start` 或 `task.input`，携带账户、设备、工作区和幂等键。
2. 云端校验用户是否拥有设备及工作区权限。
3. Gateway 校验本地工作区白名单，再调用 Codex app-server。
4. Gateway 将状态事件按协议转发；按当前产品决策，已认证且已授权的网页可接收原始 Codex 内容。
5. 云端只向该账户授权的浏览器会话转发事件。
6. 任务完成、失败、停止或超时时写入最终状态。

拒绝条件：设备离线、任务被其他 writer 占用、工作区不在白名单、权限模式不允许或幂等键重复。

## Git 读取与副作用动作

只读状态（分支、变更统计、diff）可以自动请求，但必须限制到已授权工作区。提交、推送、创建 PR、切换分支属于明确副作用动作：网页展示计划和目标，用户确认后云端发送一次性动作请求，Gateway 在本机再次校验并执行，回传结构化结果。不得接受任意 shell 字符串。

## 设备撤销

用户在网页调用 `POST /api/v1/devices/:id/revoke` 后，云端立即拒绝新的命令并标记凭据撤销；当前 Relay 会关闭 Gateway 长连接，并通过 Redis 通知其他 Relay 实例关闭同一设备连接。重新绑定必须走完整配对流程。
