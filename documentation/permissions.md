# Permissions

## 角色

| 角色 | 来源 | 范围 |
|---|---|---|
| Account owner | 云端会话 | 自己的账户、设备和工作区 |
| Account member（后续） | 云端成员关系 | 被授予的设备/工作区 |
| Gateway runtime | 本机设备密钥 + 本地策略 | 仅本机授权目录和允许的动作 |
| Codex process | Gateway 启动策略 | 由用户选择的模型、沙箱和审批策略 |
| Cloud operator | 运维身份 | 仅运维元数据；默认不能读取源码和任务内容 |

## 资源 × 操作矩阵

| 资源/操作 | Owner | Member | Gateway | Operator |
|---|---:|---:|---:|---:|
| 查看自己的设备 | 允许 | 允许（被授予） | 无 | 仅状态 |
| 绑定/撤销设备 | 允许 | 禁止 | 执行撤销连接 | 禁止默认操作 |
| 查看工作区元数据 | 允许 | 被授予 | 读取本机 | 仅故障元数据 |
| 读取任务事件 | 允许 | 被授予 | 产生/上报 | 默认禁止 |
| 启动 Codex 任务 | 允许 | 被授予 | 执行 | 禁止 |
| 查看 Git diff | 允许 | 被授予 | 读取 | 禁止源码默认访问 |
| 提交/推送/创建 PR | 二次确认 | 二次确认 | 执行已确认动作 | 禁止默认操作 |
| 修改模型/权限策略 | 允许并二次确认 | 禁止或单独授权 | 校验并应用 | 禁止 |

## 强制规则

- 所有云端资源查询必须同时按 `account_id` 和资源 ID 授权，不能只靠前端隐藏。
- 浏览器永远不接触 Codex 登录令牌、API Key、设备私钥或完整本机路径。
- Gateway 不接受任意命令；Git 和文件操作使用结构化动作及路径白名单。
- 高风险权限默认关闭；危险动作必须有可追踪的确认记录和撤销路径。
